# YouTube Brand Auto Event

Web statis (GitHub Pages) untuk membuat jadwal YouTube Live secara tunggal maupun massal pada **Brand Account** melalui YouTube Data API v3.

## Cara Pakai
1. Aktifkan GitHub Pages pada repo ini (`Settings -> Pages -> Branch: main`).
2. Buat OAuth Client ID tipe **Web Application** di Google Cloud Console dengan **Authorized JavaScript origins** mengarah ke `https://USERNAME.github.io`.
3. Buka halaman GitHub Pages, masukkan Client ID, klik **Login & Pilih Brand Account**, lalu buat jadwal event.
