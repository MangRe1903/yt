Setup Koneksi

Wajib
Kuota YouTube dihitung per Client ID (per project Google Cloud), bukan per akun. Menurut dokumentasi Google (diperbarui 15 Sep 2026), tiap project mendapat 100 upload video/hari (bucket sendiri, 1 unit/upload) dan 10.000 unit/hari untuk method lain (jadwal live 50 unit, thumbnail 50 unit, update tag 50 unit). Menambah akun di Client ID yang sama tidak menambah kuota; menambah Client ID dari project berbeda yang menambah kuota. Kalau Client ID masih status Testing, tiap akun yang dipakai wajib didaftarkan di Audience → Test users project itu.

Soal token: tidak dipakai bersama antar Client ID. Token dibuat untuk 1 pasangan akun Google + 1 Client ID. Akun yang sama yang login lewat Client ID #1 dan Client ID #2 akan punya dua token terpisah, dan token milik Client ID #1 tidak bisa dipakai untuk mengirim request atas nama Client ID #2. Kuota yang kepakai selalu dihitung ke project pemilik Client ID yang menerbitkan token itu. Jadi:
  • Banyak akun di satu Client ID: token beda-beda per akun, tapi kuotanya digabung (satu ember 10.000 unit + 100 upload/hari).
  • Akun yang sama di dua Client ID: token-nya terpisah dan kuotanya terpisah, tapi itu tetap dihitung sebagai akun yang sama di sisi Google.
  • Token akses hanya hidup sekitar 60 menit. Tiap Client ID juga dibatasi maksimal 100 refresh token per akun Google; kalau lewat, refresh token paling lama otomatis mati tanpa peringatan.
  • Client ID yang statusnya Testing: refresh token cuma berlaku sekitar 7 hari, setelah itu akun perlu login ulang. Pindahkan project ke In production kalau mau lebih awet.
Limit/akun: event
Langsung akses Brand Account tanpa membuka studio.youtube.com: Klik + TAMBAH AKUN / BRAND, pilih email Gmail, lalu di layar kedua popup OAuth pilih langsung Brand Account yang masih aktif (abaikan akun utama yang mati/ter-suspend). Token yang dihasilkan otomatis terikat ke Channel ID (UC...) Brand Account tersebut untuk semua mode (Upload Video, Jadwal Live, Stream Key, dan Playlist). Satu Gmail dengan banyak Brand Account bisa ditambahkan semuanya sekaligus ke daftar akun tanpa saling menimpa (deduplikasi berdasarkan Client ID + Channel ID). Tool otomatis memakai Client ID #1 dulu sampai habis/penuh, lalu lompat ke Client ID #2, dst.
ⓘ Alur Akses Akun Brand Meski Akun Utama Mati (Klik untuk buka panduan)▾
  1. Google Cloud Console: Buat/gunakan Project pada Gmail sehat → aktifkan YouTube Data API v3 → di OAuth consent screen / Audience tambahkan Gmail pengelola Brand Account ke Test users → buat OAuth Client ID (Web application) dengan Authorized JavaScript origins = https://USERNAME.github.io (tanpa slash akhir).
  2. Login OAuth Brand Account: Tempel Client ID di atas, pastikan Mode Brand Account tercentang, klik + TAMBAH AKUN / BRAND → pilih Gmail → pada layar kedua (Pilih akun / Brand Account) klik Brand Account yang aktif → klik Lanjutkan / Allow.
  3. Verifikasi Channel ID: Tool otomatis mengecek channels?mine=true. Jika kamu tidak sengaja memilih akun utama yang mati/suspend, tool otomatis menolaknya agar tidak merusak antrean. Pastikan kartu akun menampilkan Nama & Channel ID (UC...) Brand Account target.
  4. Jalur Pemulihan jika Email Induk Diblokir OAuth (access_denied / channelSuspended): Buka myaccount.google.com/brandaccounts (halaman Google Account non-YouTube, tidak terlempar ke channel-appeal) → klik nama Brand Account → Kelola Izin (Manage Permissions) → tambahkan Gmail baru yang bersih sebagai Manager / Owner → terima undangan → masukkan Gmail baru ke Test users Cloud Console → login di sini pakai Gmail baru.

Gambar Video (5 detik)

Mode: desain otomatis
✓ Mode Banner Tersimpan Aktif (Tanpa Upload Gambar Lagi)
Saat upload jadwal, gambar & thumbnails.set otomatis dilewati (langsung memakai Banner Channel).
Mode Video: tiap event di-render jadi video WebM 5 detik dari gambar (1280×720); thumbnail otomatis diambil YouTube dari frame video.
Mode Jadwal Live: gambar yang dipilih dipakai sebagai thumbnail JPEG (dijaga < 2 MB) lewat thumbnails.set; tidak ada video yang dirender.
• Tanpa upload gambar: desain otomatis dari judul + jadwal tiap event (beda-beda per event).
• Upload 1 gambar: gambar itu dipakai sama untuk semua event.
• Upload >1 gambar: gambar dibagi bergilir (round-robin) ke tiap event sesuai urutan di tabel, supaya thumbnail tidak sama semua. Contoh 3 gambar & 10 event: gambar 1,2,3,1,2,3,1,2,3,1.
🎨 Banner Image Channel (Solusi Anti Rate Limit 429)
2048 × 1152 • ≤ 6 MB • API
Saat thumbnails.set kena rate limit (429), YouTube otomatis memakai Banner Image Channel sebagai thumbnail default jadwal live. Ubah Banner Channel langsung via YouTube Data API v3 (channelBanners.insert + channels.update, tanpa buka YouTube Studio), otomatis di-resize ke 2048×1152 JPEG (≤ 6 MB). Jika kolom file banner di bawah kosong, otomatis memakai gambar #1 dari Bagian 3.
Default: pakai gambar #1 dari Bagian 3
